# Ejercicio 2: WebSocket Chat

## Caso Real
Crea un chat en tiempo real usando Express + Socket.io.

## Requisitos
1. Conexión WebSocket
2. Envío/recepción de mensajes
3. Rooms temáticos
4. Historial de mensajes
5. Notificaciones de usuarios online
