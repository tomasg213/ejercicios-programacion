# Ejercicio 1: API Completa con Testing

## Caso Real
Crea una API REST completa con testing usando Jest y Supertest.

## Requisitos
1. CRUD de productos con categorías
2. Tests unitarios
3. Tests de integración
4. Cobertura de código
5. Documentación básica

## Estructura de Archivos
```
01-api-testing/
├── src/
│   ├── index.js
│   ├── routes/productos.js
│   └── data/productos.js
├── tests/
│   ├── productos.test.js
│   └── integration.test.js
├── package.json
```
