# Ejercicio 2: API de Tareas

## Caso Real
Crea una API simple con Django usando serializadores básicos.

## Requisitos
1. CRUD de tareas via vistas basadas en clases
2. Templates para listar y crear
3. Formularios Django

## Estructura
```
02-api-tareas/
├── tareas/
│   ├── models.py
│   ├── views.py
│   ├── forms.py
│   └── urls.py
├── manage.py
```
