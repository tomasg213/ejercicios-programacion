## 🚀 Guía de Inicio Rápido

### JavaScript/Node.js
```bash
# Verificar instalación
node --version

# Ejemplo: Servidor REST
cd express/01-basico/01-api-rest-simple
npm install
npm start
```

### Python
```bash
# Verificar instalación
python3 --version

# Ejemplo: FastAPI
cd fastapi/01-basico/01-crud-basico
pip install -r requirements.txt
uvicorn main:app --reload
```

### React
```bash
# Crear proyecto
cd react/01-basico/01-contador-carrito
npm install
npm run dev
```

### Docker
```bash
# Primer contenedor
docker run -d -p 80:80 nginx
```
